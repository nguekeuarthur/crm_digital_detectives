# Dépôt des relevés bancaires camt.053

Déposez ici les relevés ISO 20022 exportés depuis l'E-Banking UBS (`camt.053`, ou
`camt.052` pour l'intraday). Le cron quotidien les lit, importe les écritures puis
archive les fichiers traités dans `processed/`.

Les relevés peuvent aussi être téléversés directement depuis l'écran
« Rapprochement bancaire » du CRM.

> Ce dossier contient des données bancaires : il est exclu du dépôt Git.
